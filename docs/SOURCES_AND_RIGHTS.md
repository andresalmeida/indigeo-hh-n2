# Sources, attribution and licensing scope

## Original code

The original root Python files (`analyze.py`, `render.py`, `reproduce.py`, `verify_release.py`) are distributed under MIT. The copyright notice uses the collective project attribution, **IndiGeo HH N2 contributors**. It is not a final manuscript author list or an attribution of institutional ownership.

Dependencies are installed separately and retain their own licenses. Their code and wheels are not bundled.

## Data, figures and documentation

MIT is not a blanket license for the CSV/JSON research tables, rendered figures, prose or upstream datasets. No additional general-purpose data/content license is assigned in this initial upload. Applicable statutory permissions and existing source permissions remain unaffected. A dedicated data/content license and final creator metadata remain to be established before a DOI release.

Only aggregate cantonal results and aggregate benchmark statistics are included. No raw pressure raster, boundary vector, satellite scene, parcel location, individual interpretation or credential is distributed. Sharing these aggregates does not transfer ownership of upstream material or certify rights to redistribute an upstream dataset.
